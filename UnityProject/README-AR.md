# مغامرات اليمن 4×4 — Unity 6 / URP

مشروع Unity مستقل عن نموذج Three.js السابق. يتم توليد مشهد التشغيل برمجياً عند البناء من `Assets/Editor/AndroidBuild.cs`.

## الأنظمة المضافة برمجياً
- شاشة أفقية وتحكم لمس مستمر للمركبة.
- كاميرا متابعة وخريطة مصغرة علوية للموقع والوجهة.
- بوابات المحويت وعدن وتعز ومراحل تحميل وتسليم الركاب والعودة إلى فرزة صنعاء.
- مكافآت ورصيد، استهلاك وقود مرتبط بالضغط على دواسة القيادة، ومحطة تعبئة.
- أربعة ملفات قابلة للاختيار: Hilux 2026 وLand Cruiser VXR 2026 وLand Cruiser 70/Shas 2026 وJeep Quarter، مع لون محفوظ بشكل مستقل لكل ملف.
- تضاريس إجرائية للكثبان والجبال، عناصر أشخاص ومرور وحيوانات تجريبية.
- دورة ليل/نهار، مصابيح أمامية، ومطر يمكن تشغيله وإيقافه.
- إعداد بناء Android بصيغة APK، مع ARM64 واتجاه أفقي.

## فتح المشروع
1. ثبّت Unity Hub وUnity Editor الإصدار `6000.0.32f1` مع Android Build Support وSDK/NDK وOpenJDK.
2. افتح مجلد `UnityProject` في Unity Hub وانتظر اكتمال استيراد الحزم.
3. من قائمة Unity اختر `Yemen 4x4 > Build Android APK` للبناء محلياً.

## بناء APK عبر GitHub Actions
1. فعّل ترخيص Unity Personal أو ترخيصاً مناسباً.
2. أنشئ ملف ترخيص Unity صالحاً وفق تعليمات GameCI.
3. في إعدادات المستودع أضف Repository Secret باسم `UNITY_LICENSE` وضع محتوى ملف الترخيص فيه.
4. افتح Actions ثم `Build Yemen 4x4 Unity Android APK` واضغط Run workflow.
5. عند نجاح البناء نزّل artifact باسم `Yemen-4x4-Unity-Android-APK`.

**تنبيه:** لا أستطيع إصدار ترخيص Unity أو إضافة Secret لحسابك. لذلك إعداد مسار البناء لا يعني أن APK بُني بالفعل. يلزم إضافة الترخيص وتشغيل المهمة والتحقق من نجاحها.

## حدود النسخة الحالية
البيئة والمركبات والشخصيات الحالية مولّدة إجرائياً وبأشكال أولية (prototype/greybox). ملفات نماذج سيارات 3D تجارية عالية التفاصيل ومطابقة بصرياً لموديلات 2026، وخامات PBR احترافية وخرائط طرق نهائية لم تُضف بعد. كما لم يتم فتح المشروع أو تجميعه أو اختباره داخل Unity Editor أو على هاتف Android في هذه الجلسة؛ يلزم ذلك قبل وصف اللعبة بأنها جاهزة للتسليم.
